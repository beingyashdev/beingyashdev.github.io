# BeingYashDev

A static portfolio, engineering blog, and learning notebook built with Astro, Markdown/MDX, Tailwind CSS, and Pagefind. Example projects and writing are explicitly labeled so they can be replaced with personal work.

## Local development

Use Node.js 24 and npm. Run `npm ci`, then `npm run dev` and open the URL printed in the terminal. Run `npm run check` to validate types and content, and `npm run build` to generate `dist/` and the Pagefind index. Use `npm run preview` to test the production build, including search. Search is not generated by the development server.

Edit `src/config.ts` for personal details, social links, resume, and projects. Empty links are hidden. Put a resume or project image in `public/` and use a root-relative path such as `/resume.pdf`. Replace the sample content in `src/content/` as you publish. See [CONTRIBUTING.md](CONTRIBUTING.md) for authoring instructions.

## Deploy to GitHub Pages

The configured Git remote is `beingyashdev/beingyashdev.github.io`; the matching user-site URL is `https://beingyashdev.github.io/`, so Astro uses `base: '/'`. Confirm the repository and URL if the remote changes. In the repository's GitHub settings, open **Pages** and select **GitHub Actions** as the build and deployment source. Once you choose to push to `main`, the workflow installs locked dependencies, checks types and schemas, builds and indexes the site, and deploys `dist/`. It uses GitHub's built-in token and needs no manually configured secret. This project does not change repository settings or publish itself.

If moved to a project repository, change `site` and `base` in `astro.config.mjs` and update root-relative links and assets accordingly. The current configuration intentionally targets a root user site.
